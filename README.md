# SeisLynx

**Research software for seismic inversion and physics-guided machine learning in geophysics.**

I'm Yingtian Liu, a PhD candidate in geophysics at Chengdu University of Technology. I work on prestack AVO inversion, poststack seismic impedance inversion, and rock physics–guided reservoir characterization, with an emphasis on learning from sparse well logs and seismic data.

## Featured projects

| Project | Focus | Available materials |
| --- | --- | --- |
| [Nash-MTL-STCN](https://github.com/SeisLynx/Nash-multitask-learning-prestack-three-parameter-inversion) | Prestack inversion for P-wave velocity, S-wave velocity, and density using Nash multitask learning | PyTorch research code and a Marmousi2 example |
| [DSIM-USSL](https://github.com/SeisLynx/DSIM-USSL) | Diffusion-based seismic impedance inversion with semi-supervised learning | PyTorch research code |
| [AH-RPMNet](https://github.com/SeisLynx/AH-RPMNet) | Rock physics–guided pore pressure prediction | MATLAB rock physics workflow and PyTorch pretraining code |
