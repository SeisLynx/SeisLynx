# SeisLynx

**Research software and teaching examples for seismic inversion and physics-guided machine learning in geophysics.**

I'm Yingtian Liu (刘应天), a PhD candidate in geophysics at Chengdu University of Technology. My research focuses on prestack AVO inversion, poststack seismic impedance inversion, and rock physics–guided reservoir characterization using seismic data and sparse well logs.

## Featured research

### Nash-MTL-STCN · Prestack seismic inversion

A semi-supervised PyTorch implementation for jointly estimating P-wave velocity, S-wave velocity, and density from partial angle stacks. It uses Nash multitask learning to address gradient conflicts and incorporates seismic forward modeling and low-frequency constraints.

- [Code and Marmousi2 example](https://github.com/SeisLynx/Nash-multitask-learning-prestack-three-parameter-inversion)
- [Paper in *Geophysics* (2025)](https://pubs.geoscienceworld.org/seg/geophysics/article-abstract/90/4/R175/654779/Nash-multitask-learning-semisupervised-temporal)

## Textbook companion code

### 《地球物理反演基础》 · Fundamentals of Geophysical Inversion

面向地球物理反演课程的教材配套代码。可从地震褶积正演、球体重力与磁异常、层状介质大地电磁正演等示例入手，也可查阅信号处理和深度学习去噪示例。

- [浏览教材配套代码与示例](https://github.com/SeisLynx/Textbook-Basis-of-geophysical-inversion)
